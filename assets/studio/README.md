# Studio photos (local only)

The app's Home, About, Gallery and demo proofs use the studio's own finished
prints and composites from this folder. They are photographs of client
children, so every image here is git-ignored and never leaves this computer
through the repository. Without them the app shows grayscale placeholders.

Expected files (JPG, long edge 1200 px):

- `hero.jpg`
- `photographer.jpg` (About page; DuBose holding a young client, 447 px square, from Bailey's Downloads)
- `single-1.jpg` … `single-5.jpg`, `siblings-1.jpg`, `composite-1.jpg` … `composite-4.jpg` (Gallery tab)
- `proof-a-D###.jpg`, `proof-b-D###.jpg` (demo galleries; the D number becomes the proof label)

They were rendered from the finished template PSDs in the weekly folders on
the Bran Data drive (`F:\9.8.2026`, `F:\8.24.26`), not from `_Finished` files,
which are uncropped colour.

Before the app ships to the stores, or the web build is hosted publicly, the
studio must have the families' permission to show these images.
